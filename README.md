# MarketHub Worldwide - Global Marketplace

## 🌍 Features

- **Multi-Currency Support**: 40+ currencies from 50+ countries
- **Real-time Chat**: Instant messaging between buyers and sellers
- **Product Listings**: Create, search, and filter products
- **Image Upload**: Upload up to 10 product images
- **User Authentication**: Secure JWT-based authentication
- **Responsive Design**: Works on all devices
- **Location-based Search**: Find products near you
- **Price Filtering**: Filter products by price range
- **Seller Ratings**: Rate and review sellers
- **Admin Dashboard**: Manage users and products
